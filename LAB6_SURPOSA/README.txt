JAVA METHODS LAB6

Instructor: Engr. Jamie Eduardo Rosal, MSCpE

DESCRIPTION
This project demonstrates the use of Java methods, including void methods, return-value methods, parameters, and recursive methods.

ACTIVITIES
1. greetUser() - Displays a greeting message.
2. Arithmetic Methods - Performs addition, subtraction, multiplication, and division.
3. factorial() - Calculates the factorial of a number.
4. sumArray() - Calculates the sum of array elements.
5. isPrime() - Checks if a number is prime.
6. maxInArray() - Finds the largest number in an array.
7. gcd() and lcm() - Calculates the GCD and LCM of two numbers.
8. Recursive Factorial - Calculates factorial using recursion.
9. Recursive Fibonacci - Calculates the Fibonacci sequence using recursion.
10.isPalindrome() - Checks if a word reads the same forwards and backwards.
